About this demo
This platform connects two standalone products: Product A (Budget) and Product B (Analytics). You log in here and the platform knows which products you have access to. Navigation adapts automatically. Data flows between the products via the platform without them knowing about each other.
Technical
Authentication:
  POST /api/login → Validates against hardcoded demo users
  → Creates JWT with: user_id, name, role, org_unit, products, primary_product
  → Stored as cookie (platform_token, httpOnly: false for shell.js)

Platform Shell:
  Each product loads <script src="http://localhost:3000/shell.js">
  → Reads JWT from cookie → Renders shared header
  → Navigation based on products[] in JWT
  → Entitlement check: redirect if unauthorized

Technologies: Express, jsonwebtoken, cookie-parser
